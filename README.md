# Brick Breaker DX

A modern Android brick breaker game, built in Kotlin and Jetpack Compose. It is a clean-room rebuild inspired by the classic BlackBerry game and contains no original BlackBerry art, assets or branding.

- Portrait only, scales across phone sizes
- Drag-ring paddle control, 8 levels, 7 power-ups
- Synthesised sound, no external assets

## Play

Download the latest APK from the [Releases page](https://github.com/rubble-za/Brick-Breaker-DX/releases) and sideload it. The APK is debug-signed.
